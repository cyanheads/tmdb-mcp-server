# 0.3.0 — 2026-11-20

## Added

- **`tmdb_get_season`** includes episode IDs, vote counts, episode types, and directing and writing credits when TMDB provides them. ([#13](https://github.com/cyanheads/tmdb-mcp-server/issues/13))
- **`tmdb_get_movie`** includes collection membership. Add `"collection"` to `append` to fetch the films in release order, with undated films last. ([#17](https://github.com/cyanheads/tmdb-mcp-server/issues/17))

## Changed

- **`tmdb_get_season`** now omits `episodes[].guest_stars` by default. Pass `include_guest_stars: true` to include them. ([#13](https://github.com/cyanheads/tmdb-mcp-server/issues/13))
- **Bun** now requires 1.4.4 or later.

## Fixed

- **`tmdb_get_movie` and `tmdb_get_show`** page cast and crew independently with totals and `next_credits_page`. TV credits cover the whole series and include roles, jobs, and episode counts. Title resources return the first page and totals. ([#11](https://github.com/cyanheads/tmdb-mcp-server/issues/11))
- **`tmdb_get_person`** uses the first credited episode year for TV credits when available, falls back to the series premiere year, and includes credited episode counts when supplied. ([#12](https://github.com/cyanheads/tmdb-mcp-server/issues/12))
- **`tmdb_get_watch_providers`** identifies the resolved title and year when available and lists the regions with TMDB provider data. Provider lists still correspond to the requested region. ([#14](https://github.com/cyanheads/tmdb-mcp-server/issues/14))
- **MCPB cleanup** strips dependency skill documentation while preserving SDK runtime modules.
