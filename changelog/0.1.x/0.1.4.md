# 0.1.4 — 2026-10-07

## Changed

- **Framework adoption** adds integer-to-string input repair (0.13.9), recovery hints and request IDs on tool/resource errors (0.13.10), and field-first resource validation messages (0.13.12).
- **Docker** uses Bun 1.4.0 → 1.4.2 and cross-installs production dependencies on the build platform, installs OpenTelemetry at framework peer ranges through supply-chain checks, and prunes musl-only packages from the glibc runtime.
- **Development tooling and documentation** sync framework skills, definition and packaging checks, tag validation, CodeQL language categories, and optional logging configuration guidance.
- **Package exclusions** keep built MCPB bundles out of npm and exclude cache, logs, idea notes, env files, and registry credentials from distribution contexts.

## Fixed

- **MCP Registry launch metadata** uses `npx` without npm-script arguments and fixes `MCP_TRANSPORT_TYPE=http` for the HTTP entry.
