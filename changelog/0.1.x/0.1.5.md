# 0.1.5 — 2026-10-17

## Added

- **`tmdb_get_person`** accepts `credits_page` for independent 50-entry cast and crew pages, with full totals, `next_credits_page`, and executable continuation guidance that preserves language ([#4](https://github.com/cyanheads/tmdb-mcp-server/issues/4)).

## Changed

- **Input repair** accepts numeric-string person IDs and treats optional `language: null` as omitted through the adopted framework; validation diagnostics are bounded.
- **Distribution and development** use Bun 1.4.3, exclude development material from the desktop bundle, and sync framework development guidance.

## Fixed

- **TV discovery sorting** maps release-date sorts to first-air-date order and discloses popularity fallback for movie-only revenue sorts; only caller-supplied date bounds apply ([#1](https://github.com/cyanheads/tmdb-mcp-server/issues/1)).
- **Discovery recovery** uses `TMDB_DEFAULT_REGION` as the missing-region example without defaulting availability queries ([#2](https://github.com/cyanheads/tmdb-mcp-server/issues/2)).
- **Empty search, discovery, and trending text** includes returned pagination, including zero total pages ([#6](https://github.com/cyanheads/tmdb-mcp-server/issues/6)).
